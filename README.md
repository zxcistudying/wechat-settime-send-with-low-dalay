# 普通微信低延迟定时发送

这是一个基于 AutoHotkey v2 的普通微信桌面自动化脚本，不使用微信 API。

## 使用前准备

1. 安装 AutoHotkey v2：https://www.autohotkey.com/
2. 打开电脑上的普通微信。
3. 为了最低延迟，提前点开要发送消息的聊天窗口。
4. 修改 `config.ini` 里的 `send_at` 和 `message`。
5. 双击 `run.bat`，脚本会常驻等待，到点自动发送。

## 推荐配置

默认 `mode=preselected`，也就是目标聊天需要提前打开并选中。这种模式到点时只做：

1. 激活微信窗口
2. 粘贴消息
3. 按 Enter

这是普通微信 UI 自动化里延迟最低、也最稳定的方式。

## 可选联系人搜索模式

如果一定要让脚本自动搜索联系人，可以把 `config.ini` 改成：

```ini
mode=search
target_chat=文件传输助手
advance_activate_ms=1200
```

搜索模式会在发送时间前提前激活微信并搜索联系人，到点再发送。它比预选聊天模式更容易受微信版本、搜索结果、窗口焦点影响。

## 注意事项

- 电脑不能锁屏。
- 微信必须已经登录。
- 微信的发送快捷键建议设置为 Enter 发送。
- 脚本会临时占用剪贴板，发送后按配置恢复。
- 这不是硬实时系统，普通桌面自动化通常能做到接近指定秒级时间，但会受系统负载、微信响应、窗口焦点影响。
